# 來源雙蜂 RGB 訊號檢查結果 (不佔節號)

預登記 adab39f [paired-rgb-v1]。只用原25支W/G訓練片,已知真框/身分後看固定局部描述是否偏好原GT接法,不是偵測器或追蹤部署成績,未訓練模型。BEE24-14的原ID68在第60幀重複,整片停列,未刪行補挑。其餘24片按封存SHA名單選93對,每片至多4對;同蜂重複配對不當獨立蜂箱。

正/負/棄 = 原GT接法較好/交換較好/棄權。S=(正−負)/入選數,不是只在有投票時算準確率。可讀(valid)包括沒有辨識訊號的棄權,可投票(informative)才是正+負。時移正票只代表同一固定接法的代價偏好,不是已知時移影像裡真的追對身分。

全部日期對照均能配回同名單,原/時移相同N=93;雙邊可讀交集另列,沒有把棄權從主分母刪掉。原資料19正、2負、72棄,其中67對因兩蜂描述太近,另2對兩接法代價太近、3對裁圖或跨時完整框支援不足。原/時移合計186臂中180可量測,6臂不可用;180不是180個有效身分投票。

W有投票時的正票率8/9與時移24/27相同,但時移能投票的臂是原的3倍。事後局部界:保持原9對可投票/28對棄權名單、並以本次已固定的時移21/37作比較,即使9對全改成正,也只有9/37<21/37。它不限制更換描述、棄權規則、取樣或新資料後的表現,也不證明時移影像沒有蜂。

W/G正負投票覆蓋分別9/37=24.32%、12/56=21.43%,都小於25%;S也都小於0.20,W的原S更低於時移。片數/配對數8對及3片門檻雖足夠,不能因此說整個訊號覆蓋門檻通過。跨界子集38對、S=7/38>0,其數量/方向條件成立,但主閘門未過,所以聯合入口交錯解釋閘門仍未過。此固定六維描述不能作本輪實片模型的主要證據;不把它外推成所有RGB或外觀學習無用。
